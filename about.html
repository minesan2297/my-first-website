Giới Thiệu Về Tôi

Khám phá hành trình học tập, niềm đam mê phát triển web và bộ kỹ năng chuyên môn tôi đã tích lũy.

Tiểu Sử & Mục Tiêu Nghề Nghiệp

Xin chào! Tôi là Đinh Bách Hợp, hiện là sinh viên chuyên ngành Công nghệ Thông tin (Lớp CNTT K23C). Tôi có sự yêu thích đặc biệt đối với việc thiết kế và lập trình giao diện người dùng (Frontend Development).

Mục tiêu trước mắt của tôi là ứng tuyển vào vị trí thực tập sinh hoặc nhân viên Frontend / Web Developer, đem những kiến thức về HTML5, CSS3 hiện đại, tư duy thiết kế Mobile-First và tác phong làm việc kỷ luật đóng góp vào các sản phẩm thực tế của doanh nghiệp.

Học Vấn & Quá Trình Rèn Luyện

Trong suốt quá trình học tập tại lớp CNTT K23C, tôi đã hoàn thành toàn diện khóa học phát triển Web nền tảng, nắm vững các nguyên lý cấu trúc W3C, thao tác thuần thục với CSS Box Model, Flexbox, CSS Grid, kỹ thuật Responsive Design và quy trình quản trị mã nguồn chuyên nghiệp với Git/GitHub.

Kỹ Năng Chuyên Môn

Các công nghệ và công cụ tôi sử dụng thường xuyên trong việc xây dựng và phát triển các trang web hoàn chỉnh:

  • HTML5 Ngữ Nghĩa (Semantic Elements) Thành thạo
  • CSS3 & Responsive Web Design Thành thạo
  • CSS Grid & Flexbox Layouts Nâng cao
  • Mobile-First Methodology Thành thạo
  • Git & GitHub Version Control Cơ bản
  • CSS Checkbox Hack & Hamburger Menu Thành thạo
  • JavaScript ES6+ Cơ bản Đang học
  • Chrome DevTools & Debugging Thành thạo
  • Tối ưu hóa hình ảnh & Hiệu năng Web Tốt
